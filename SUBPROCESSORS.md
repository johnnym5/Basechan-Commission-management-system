# Published Subprocessors List

*Last Updated: October 2026*

Basechan International uses the following third-party infrastructure providers ("Subprocessors") to deliver Basechan CMS. Each provider is bound by data protection agreements consistent with GDPR Article 28 and CCPA requirements.

## Infrastructure & Service Providers

| Subprocessor Name | Purpose / Function | Data Location | Security Certifications |
|---|---|---|---|
| **Google Cloud Platform (GCP) / Firebase** | Firestore NoSQL database, Firebase Web Hosting, and Firebase Authentication | Multi-Region (United States / Global CDN) | SOC 1, SOC 2 Type II, SOC 3, ISO 27001, ISO 27017, ISO 27018, HIPAA compliant infrastructure |
| **Google Identity Services** | Google OAuth single sign-on user identity verification | Global | SOC 1, SOC 2, ISO 27001 |
| **SheetJS (Community / Open Source)** | Client-side Excel workbook parser library | Local Browser Client (Zero network transmission) | Client-side JavaScript library executing entirely inside user browser memory |

## Subprocessor Updates

Basechan International notifies system administrators at least 14 days prior to adding or replacing any subprocessor. You may subscribe to subprocessor notifications by contacting privacy@basechaninternational.com.
